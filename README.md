# The Parlour — Game Table

Twenty-six classic and casual games in one single-file web app (English, Persian, Azerbaijani).

## Files
- `ads.html`, `new.html`, `head_lines.txt` — the game source.
- `build.py` — builds the website, offline and no-ads versions (needs the `webpkg` folder from the source zip).
- `three.min.js` — 3D library (MIT licence) used by Jenga and Billiards.
- `cloudflare-worker.js`, `wrangler.toml` — the player counter and clans service (Cloudflare Worker).
- `parlour-offline-noads.html` — the one-file offline version without ads.
